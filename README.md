# GymHub
🏋️ Fitness Club Website

A modern and responsive fitness club website designed to showcase a gym, its training programs, membership plans, trainers, and facilities.

✨ Features

• 🏋️ Modern and responsive design
• 💪 Training programs and workout sections
• 👤 Personal trainer profiles
• 💳 Membership plans
• 📸 Fitness and gym gallery
• 📱 Mobile-friendly layout
• 🎨 Clean and modern UI
• ⚡ Smooth animations and interactive elements

🛠️ Technologies

• HTML5
• CSS3
• JavaScript

🎯 Project Goal

The goal of this project is to create a modern fitness website that is easy to use, visually attractive, and suitable for a real gym or fitness club.
